Tecnologia em Análise e Desenvolvimento de Sistemas

Curso Superior | Duração: 03 anos

Sobre o curso:

O Tecnólogo em Análise e Desenvolvimento de Sistemas deverá ser capaz de analisar, projetar, documentar, especificar, testar, implantar e manter sistemas computacionais de informação. Será um profissional habituado a usar o raciocínio lógico, a empregar linguagens de programação e metodologias de construção de projetos, e preocupado com a qualidade, a usabilidade, a robustez, a integridade e a segurança de programas computacionais.

  • Engenharia de Requisitos
  • Interação Humano-Computador
  • Linguagem de Programação 1
  • Desenvolvimento Web
  • Arquitetura de Computadores
  • Inglês Técnico
2º Período
  • Engenharia de Software
  • Banco de Dados 1
  • Linguagem de Programação 2
  • Desenvolvimento de Sistemas Web 1
  • Estrutura de Dados 1
  • Comunicação e Expressão
3º Período
  • Banco de Dados 2
  • Linguagem de Programação 3
  • Redes de Computadores
  • Estrutura de Dados 2
  • Práticas em Sociedade e Informática
