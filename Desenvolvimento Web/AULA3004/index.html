Aula 30/04/2026 - Exercícios de fixação

Identificação de conceitos:

Escreva com suas palavras a diferença entre: framework, biblioteca, CSS framework e design system. Depois, cite um exemplo de cada categoria estudada nesta aula.

Framework: estrutura padrão pronta que pode ser reutilizada por diferentes desenvolvedores e sistemas. (Angular)

Biblioteca: conjunto de recursos possíveis de utilizar - como funções. (Pandas - Python)

CSS framework: conjunto de classes CSS prontas e padronizadas. (Bootstrap)

Design system: conjunto de diretrizes visuais (Material Design - Google)
